# 分流標籤

工程技能使用五種標準分流角色；此檔案將角色對應至本專案追蹤器實際使用的標籤。

| 標準角色 | 追蹤器標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者尚待評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 AFK agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要由人員實作 |
| `wontfix` | `wontfix` | 不會處理 |

技能提及某一分流角色時，使用此表右欄對應的標籤字串。若既有標籤名稱改變，更新右欄即可。

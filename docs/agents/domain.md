# 網域文件

工程技能在探索程式碼前，依以下規則使用本專案的網域文件。

## 探索前閱讀

- 根目錄的 `CONTEXT.md`。
- 與目前工作相關的 `docs/adr/` ADR。

若這些檔案或目錄尚不存在，請直接繼續，不提示缺少或主動建立；`/domain-modeling` 會在實際需要時建立它們。

## 文件結構

本專案使用單一脈絡：

```
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 使用詞彙表用語

議題標題、重構提案、假設與測試名稱應使用 `CONTEXT.md` 中定義的網域詞彙，避免改用被明確排除的同義詞。若概念不在詞彙表中，應先確認不是引入了不屬於專案的語言；若確有缺口，交由 `/domain-modeling` 處理。

## 標示 ADR 衝突

若輸出內容與既有 ADR 衝突，必須明確標示衝突，而非靜默覆寫決策。
